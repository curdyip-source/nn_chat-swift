# История правок — NufNaf Chat (iOS)

Человекочитаемый журнал заметных изменений. Технические детали — в git-коммитах.

## 2026-06-27

### Realtime / синхронизация (фаза 2)
- Локальный кеш чата на устройстве + дельта-синхронизация по курсору вместо перекачки всей годовой ленты: история показывается мгновенно при запуске, подтягиваются только изменения.
- Живые обновления по SSE (`/messages/stream`): сообщения, статусы заказов/инвентаризаций/приёмок и позиции обновляются в реальном времени.
- SSE-клиент переписан на `URLSessionDataDelegate` (вместо `URLSession.bytes`, который буферил поток на устройстве) — события приходят мгновенно.
- Резервный дельта-поллинг (4с) на случай, если SSE не поднимется на конкретной сети.
- Форс HTTP/2 для SSE; декод событий на главном акторе (фикс Swift 6).

### Производительность
- Мемоизация парсинга дат (`HomeMessageDateParser`) — убрала микро-хитч на середине горизонтального свайпа chat↔CRM (раньше тысячи дат парсились на каждый кадр).

### Уведомления
- Мгновенный refresh чата при приходе пуша в форграунде (раньше ждал до 4с поллинга).

### Анимация открытия/закрытия карточки заказа
- Данные заказа засеваются из кеша — контент (позиции, цены) въезжает вместе с анимацией, а не «вылетает» после загрузки.
- Статусы заказа переведены с `LazyVGrid` на не-ленивую сетку — въезжают вместе со всем контентом, а не «рендерятся на месте».
- Единый путь закрытия для кнопки «Назад» и свайпа (одинаковый сдвиг карточки).
- Клавиатура уходит вниз плавно и синхронно с карточкой (без «улёта вправо» и без рывка-исчезновения).
- Док комментария (текстфилд) уезжает вместе с карточкой при закрытии.
- Убран deprecated `UIScreen.main`.
